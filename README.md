# 游戏对话与任务编辑台

本地单机使用的游戏对话命令行工具。当前已实现对话文件的整份校验、单步
分支预览与三种只读查询；任务编辑等写入功能尚未实现（见文末「尚未实现」）。

程序只处理 UTF-8 编码的 JSON 对话文件，仅依赖 Python 3 标准库，无需联网、
无需安装第三方包，也不需要数据库初始化。

## 对话数据的组织（以 sample.json 为例）

`sample.json` 是一个岔路口对话：

- 顶层字段 `start` 的值是起始节点的编号，样例中为 `"start"`。
- 顶层字段 `nodes` 是节点数组；每个节点包含：
  - `id`：节点编号；
  - `text`：节点文字；
  - `options`：选项数组，每项包含选项文字 `text` 和目标节点编号 `target`。
- 选项的 `target` 指向另一个节点的 `id`。样例中起点的两个选项分别指向
  `forest`（森林）和 `river`（河边）。
- `options` 为空数组表示该节点是对话结尾，样例中的 `forest` 与 `river`
  都是结尾节点。

编号规则：

- 节点编号是至少含一个非空白字符的字符串，查找时按原字符串精确匹配，
  首尾空白不会被裁剪。
- 选项编号从 1 开始，按 `options` 数组的顺序确定：样例起点的「向左走」
  是 1，「向右走」是 2。

## 快速开始

在项目目录下依次执行下面两条命令。

**1. 校验对话文件**

```sh
python dialogue.py validate sample.json
```

标准输出只有一行：

```
校验通过
```

退出码为 0，标准错误为空。

**2. 预览一个分支**

```sh
python dialogue.py preview sample.json --choice 1
```

标准输出只有所选选项指向的下一节点文字加换行：

```
你到了森林。
```

退出码同样为 0，标准错误为空。两次运行都不会改动 `sample.json`，
文件字节保持不变。

## 单步预览

```
python dialogue.py preview <文件路径> --choice <选项编号> [--node <节点编号>]
```

- 预览只取下一节点（所选选项 `target` 指向的节点）的文字并输出，不输出
  其他内容。
- 省略 `--node` 时从 `start` 指向的起始节点出发；显式指定 `--node` 时
  从对应编号的节点出发，编号按原字符串精确匹配。
- 预览是只读的：只看一步，不连续前进，也不保存任何游玩进度。

## 其他只读查询

- `inspect`：查看一个节点的编号、文字和全部选项（省略 `--node` 时查看
  起始节点），不选择选项。
  `python dialogue.py inspect <文件路径> [--node <节点编号>]`
- `references`：查询直接指向某节点的入向引用（省略 `--node` 时查询起始
  节点），逐项列出来源节点、选项编号与选项文字，不展开间接引用。
  `python dialogue.py references <文件路径> [--node <节点编号>]`
- `unreachable`：报告无法从 `start` 沿选项 `target` 到达的节点编号
  （起点本身始终可达）。
  `python dialogue.py unreachable <文件路径>`

全部命令的回归测试说明与运行方式见 [TESTING.md](TESTING.md)。

## 错误处理

下列失败情况统一以退出码 2 结束，标准输出为空，标准错误只输出一条中文
说明，不输出调用栈：

- **文件无法读取**（如路径不存在）：报告无法读取文件及系统原因。
- **UTF-8 解码失败**：报告文件不是合法的 UTF-8 编码。
- **JSON 语法错误**：报告中包含出错的行号与列号。
- **结构与引用非法**：如缺少字段、节点编号重复或为空、`start` 或某个
  `target` 指向不存在的节点等；说明中包含对应定位，例如 `nodes[1].id`、
  `nodes[0].options[1].target` 或 `start`。
- **预览选择越界**：例如对样例执行
  `python dialogue.py preview sample.json --choice 3`，标准错误为
  `--choice 3 不在起点 'start' 的有效选项编号范围 1 到 2 内`。

校验范围说明：

- 预览与三种查询在输出结果前，都会先对整份数据完成与 `validate` 相同的
  校验。即使错误位于不可达节点，或位于本次没有选中的分支，仍然会阻止
  结果输出。
- 合法的循环引用不会导致校验失败；存在不可达节点本身也不会导致校验失败
  （不可达节点可用 `unreachable` 查看），但不可达节点内部的结构或引用
  错误同样会使整份校验失败。
